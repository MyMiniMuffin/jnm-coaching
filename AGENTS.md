# AGENTS.md

## Git

- Lever alle endringer som pull request til `main` fra en egen branch. Push aldri direkte til default-branch (`main`).
- Kjør testene (`node --test tests/*.cjs tests/*.mjs`) og `npm run build` før push.
- Ikke legg til `Co-Authored-By`, `Claude-Session` eller annen Claude-attribusjon i commit-meldinger eller PR-beskrivelser.
